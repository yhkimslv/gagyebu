내 기기끼리 동기화

컴퓨터와 아이폰에 같은 세 값을 넣으면 내 가계부가 기기끼리 자동으로 합쳐져요. 혼자 쓰신다면 켜지 않아도 됩니다.

저장소 만드는 방법 (무료, 5분)
  1. supabase.com에 무료 가입 후 New project를 만듭니다.
  2. SQL Editor를 열고 앱 폴더의 supabase_setup.sql 내용을 붙여넣고 Run 합니다.
  3. Settings → API에서 Project URL과 anon public 키를 복사해 아래에 넣습니다.
  4. [새 코드 만들기]로 내 코드를 만든 뒤, 다른 기기에도 같은 세 값을 넣으면 끝!

⚠ 커플 가계부와 다른 코드를 쓰세요. 코드가 같으면 두 가계부가 섞입니다.

알림

알림 꺼짐
