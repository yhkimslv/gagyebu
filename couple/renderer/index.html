커플 공유 (동기화)

두 사람이 같은 세 값을 넣으면 각자 입력한 내역이 하나의 가계부로 합쳐져요. 처음 한 번만 만들면 됩니다.

공유 저장소 만드는 방법 (무료, 5분)
  1. supabase.com에 둘 중 한 명이 무료 가입 후 New project를 만듭니다.
  2. SQL Editor를 열고 앱 폴더의 supabase_setup.sql 내용을 붙여넣고 Run 합니다.
  3. Settings → API에서 Project URL과 anon public 키를 복사해 아래에 넣습니다.
  4. [새 코드 만들기]로 커플 코드를 만들고, 세 값을 상대에게 알려주면 끝!

⚠ 이 세 값을 아는 사람은 가계부를 볼 수 있어요. 둘만 알고 계세요.
